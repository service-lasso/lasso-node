# Node.js for Service Lasso

Run a Node service with a managed runtime provider. Lasso installs the Node package and resolves the provider for services that declare it as a dependency.

**[Run an app with Service Lasso](https://github.com/service-lasso/service-lasso/blob/develop/docs/integration/README.md)** · [Choose an app template](https://github.com/service-lasso/service-lasso/blob/develop/docs/reference-apps.md)

This repository packages official Node.js distributions; consume its released service manifest when building your inventory. You do not need to clone this packaging repository to run your application.
